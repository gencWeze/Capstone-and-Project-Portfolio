### 2. Loviso — Location Advisor

**Type:** Collaborative Capstone Project  
**Role:** Machine Learning Team Member  
**Team Size:** 6 members

Loviso is a mobile application designed to help promote local MSMEs and regional commodities by making them easier for users to discover.

As part of a three-member Machine Learning team, I collaborated on the development of recommendation features to help users discover relevant MSMEs. Our work included collecting location-related data through Google Maps scraping, developing location-based recommendations and collaborative filtering, and incorporating transportation options to help users navigate to MSME locations.

Key Contributions:
- Collected location-related data through Google Maps scraping.
- Collaborated on the development of location-based recommendation features.
- Worked with the team on collaborative filtering to support personalized recommendations.
- Contributed to features that help users identify transportation options for reaching MSME locations.

**Repository:** [Loviso Capstone Project](https://github.com/MFaishalRamadhan/Capstone)
